# MCAW RiskEngine Simulator (offline)

MVP goals:
- Load **FRAME** JSONL trace generated by Kotlin tests
- Re-run a TypeScript port of `RiskEngine.kt`
- Plot `rawRisk`, `emaRisk`, `level`
- Detect first mismatch vs Kotlin output (`level`, `reasonBits`, `riskScore` within epsilon)

## Run UI

```bash
cd sim
npm install
npm run dev
```

Open the local URL shown by Vite. Load a `*.jsonl` file.

## Golden compare (CLI)

```bash
cd sim
npm install
npm run golden -- ../path/to/SCENARIO_FRAME_TRACE.jsonl
```

Expected JSONL line format (per frame):

```json
{"type":"FRAME","tSec":6.5,"in":{...},"out":{"level":1,"riskScore":0.472,"reasonBits":12345678}}
```

Notes:
- `scripts/golden-compare.mjs` uses `dist-engine/RiskEngineRef.node.mjs` (node-friendly copy of the engine).
- UI uses `src/engine/RiskEngine.ts`.

## What-if tuning

UI includes an early experimental toggle: **dynamic distance thresholds** based on time gap.
This is intentionally **not** part of golden matching yet; it's for interactive exploration before Android changes.
